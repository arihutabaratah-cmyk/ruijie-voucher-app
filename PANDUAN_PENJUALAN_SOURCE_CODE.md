## 💻 Panduan Instalasi untuk Pembeli (Cara Menjalankan)

Pembeli Anda memiliki 3 opsi mudah untuk menggunakan aplikasi ini:

### Opsi 1: Tanpa Hosting / Offline (Langsung di Komputer Kasir)
- Pembeli cukup mengekstrak file ZIP.
- Dobel-klik file **`index.html`** di browser (Google Chrome / Microsoft Edge).
- Aplikasi langsung siap digunakan 100% offline!

### Opsi 2: Upload ke Hosting Gratis (Vercel / GitHub Pages / Netlify)
- Pembeli dapat mengupload folder project ke **Vercel** atau **GitHub Pages** (gratis selamanya, sudah support HTTPS).
- Menghasilkan link web online seperti `https://voucher-tokoanda.vercel.app` yang bisa dibuka dari HP kasir manapun.

### Opsi 3: Upload ke Web Hosting cPanel / VPS
- Masuk ke cPanel ➔ File Manager ➔ `public_html`.
- Upload dan ekstrak file ZIP.
- Langsung aktif pada domain/subdomain pembeli!

## 💾 Fitur Keamanan Database Pribadi Anda Sendiri

Untuk penggunaan pribadi Anda sekarang:
1. **Fitur Backup 1-Klik:**  
   Buka aplikasi ➔ klik tombol **`💾 Backup DB`** ➔ klik **`Download Backup Database (.json)`**.
2. **Penyimpanan Ganda:**  
   Aplikasi sekarang otomatis menyimpan ke **LocalStorage** dan **IndexedDB** secara bersamaan, sehingga data voucher dan saldo agen Anda tetap tersimpan utuh dan tidak mudah terhapus oleh pembersihan cache biasa.
3. **Restore Cepat:**  
   Jika Anda berganti laptop atau komputer kasir, cukup buka aplikasi baru ➔ klik **`💾 Backup DB`** ➔ upload file `.json` backup Anda, seluruh data akan pulih dalam 1 detik!
